# Referencias de diseño

Imágenes de referencia (mockups, capturas, bocetos) para construir las interfaces de la app.

Estas imágenes **no** forman parte de la app: no son recursos `drawable` y no se empaquetan en el APK.

## Convención sugerida

Nombrar cada imagen según la pantalla que representa, por ejemplo:

- `01_login.png`
- `02_home.png`
- `03_detalle.png`
